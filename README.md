# New Zealand — Travel Landing Page

Це репозиторій лендінгу, розробленого для презентації туристичних турів.

**Live Demo:** [Переглянути сайт](https://elizabethblock.github.io/New-Zealand/)

## Огляд проекту

Сайт розроблено як маркетингову сторінку ("продаючий" лендінг) з метою зацікавити користувача подорожжю. Основний акцент зроблено на візуальній складовій та зручній подачі інформації про маршрут.

## Технологічний стек

* **HTML5:**
* **CSS3 (SCSS):**
    * **CSS Grid Layout:** Для створення макетів сторінки.
    * **Flexbox:** Для вирівнювання елементів навігації та карток.
    * **Responsive Design:** Повна адаптивність під мобільні пристрої, планшети та десктопи.
    * **BEM методологія:** Для іменування класів та організації стилів.
* **JavaScript:** Базова взаємодія з елементами інтерфейсу.

## Особливості (Highlights)

* **Pixel Perfect:** Верстка точно відповідає дизайнерському макету.
* **Typography:** Використання підключених шрифтів для створення унікального стилю.
* **Interactive Elements:** Ховер-ефекти на кнопках та картках, плавна прокрутка.
* **Images Optimization:** Оптимізована робота з графікою (SVG іконки, адаптивні зображення).
